jimeng-novel script outline — AI 生成分集大纲（剧本工具）

用法: jimeng-novel script outline [选项]

参数:
  --project-id <string>
      画布 ID；不传时从当前目录向上找 .jimeng/config.json（jimeng-novel init 写入）
  --input <string>
      JSON 对象（高级入口，字段见 schema get）
  --input-file <string>
      从文件读取 --input 的 JSON
  --request-id <string>
      幂等键：同一个 request-id 重复提交只会找到原任务
  --wait <int>
      最多等待的秒数；不传只查一次；到期仍未完成返回 status=running（exit 0），再执行同一条命令即可，不要重新提交。建议值（2026-11-05 实测，提交到完成）：图片 120（n=59，p50 39s、p90 71s、max 136s）；视频 480（n=51，p50 221s、p90 319s、max 414s；seedance2.0_vision 最慢）。工具单次超时比这短时，按自己的超时给值，未完成就再跑 node result，或放进后台任务
  --out <string>
      成功后把结果正文写进这个 md 文件；从不覆盖：已有文件内容不同（比如你改过）就先移到同目录 old/<名>.<序号>.md，输出里写明
  --episode-num <int>
      字段 episode_num（服务端必填）
  --idea <string>
      创意或故事梗概；与 ref_content 至少一个非空
  --idea-file <string>
      从文件读取 --idea
  --model-key <string>
      剧本模型 key；留空用 script_bird
  --ref-content <string>
      参考文本，如小说片段或补充设定
  --ref-content-file <string>
      从文件读取 --ref-content
  --script-localization <cn|i18n>
      字段 script_localization
  --team-id <string>
      仅本次使用的空间；0 为个人。已有对象沿用原空间，新操作用账号默认；仅使用目录默认项目时校验目录绑定
  -j, --json
      输出 JSON 信封 {status,data,error,context}
  --jq <表达式>
      对 JSON 信封执行 jq（字符串结果原样输出），如 --jq '.data.items[].key'
  --full
      不截断长文本和长列表

返回: thread_id、run_id、requestId；带 --wait 时同 script result

示例:
  jimeng-novel script outline --episode-num 10 --idea-file <文件.md> --wait 120 --out <文件.md>
