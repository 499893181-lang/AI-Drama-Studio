本轮直接改造现有应用，保留已实现的故事、文字候选与审阅、图片、视频任务、本地剪辑和导出能力。附件中的示例项目与山水画面只用于确定布局，没有写入生产项目或冒充生成结果。实际测试、截图和数据保留证据见[本轮验收记录](ui-c-v10-acceptance.md)。

实施分支为 `codex/ui-c-adjusted-v10-20261116`，基于 PR #8 的 `codex/canvas-video-execution-v09-20261116`，基线提交为 `1900352f1ff4fd6142906d4a89e437bd700b932f`。这是依赖前序功能的堆叠 PR，不应改从缺少这些功能的 main 覆盖实施；本轮不自动合并。

## 布局与公共规范

左侧完整保留两层结构：最窄图标栏，以及相邻的项目面板。项目面板显示真实项目名称、时长、画幅和可读取的项目素材缩略图，支持切换项目；下方依次为故事、剧本、分镜、画面、视频、配音剪辑、导出七步，以及角色与场景、风格库、预算、设置四个资源入口。

顶部保留项目路径和必要的次级操作，不再显示与左侧重复的横向七步流程。当前步骤内容在主工作区独立滚动；底部单独显示下一步说明、返回或保存动作，以及当前主要操作。长文本和较多镜头在各自区域滚动，底部按钮不压住编辑区。

公共实现集中在：

- [`public/studio-config.js`](../public/studio-config.js)：软件名称暂为“AI 短剧”，统一维护七步与四资源导航，可在一处更名。
- [`public/studio-shell.js`](../public/studio-shell.js)：项目面板、路径、底部操作与真实步骤状态；移动原有编辑和操作节点，沿用原页面事件与禁用条件。
- [`public/studio.css`](../public/studio.css)：蓝白颜色、浅灰边线、字号、中文系统字体回退、间距、圆角及各区域尺寸变量；各页面共用。
- [`src/workflow.mjs`](../src/workflow.mjs)：只读汇总当前保存版本、过期信息、人工审核、选用与文件状态；由 `GET /api/projects/:id/workflow` 提供导航数据。

高级参数、手册扩展、实体 JSON、历史版本、原始任务和诊断仍可展开查看。左侧区分已完成、进行中、待处理、需复核；这些状态只表示当前工作台资料的保存或人工选用情况，不表示正式四岗位 guard PASS、交接有效或作品已验收。没有修改正式账本和修正次数。

## 页面与操作

默认端口为 4317，本机此次工作台使用 [http://127.0.0.1:4320](http://127.0.0.1:4320)。这些都是本机地址；公开 GitHub 仓库不提供远程访问个人项目或认证的能力。导航会携带当前 `projectId`，表中省略该参数。

| 步骤或资源 | 页面 | 当前主要操作与边界 |
| --- | --- | --- |
| 故事 | `/` | 输入构思和项目要求，保存项目；扩写仍由本人确认后调用真实 Codex。 |
| 剧本 | `/creative.html?stage=script` | 生成剧本候选、独立审阅、载入人工编辑、保存并继续；已保存正文可只读查看，不自动覆盖人工稿。 |
| 分镜 | `/creative.html?stage=storyboard` | 左侧实际图片或明确空态，右侧画面／动作／衔接，下方镜头缩略图与可展开费用设置；确认分镜后进入画面步骤，不自动出图。 |
| 画面 | `/images.html` | 导出任务包、导入实际文件、检查和人工选用；保留旧图、来源声明及版本。 |
| 视频 | `/canvas-video.html` | 检查选用图、参数、同节点报价和具体范围授权；原任务查询、下载、候选检查与选用沿用既有门槛。 |
| 直连视频 | `/video.html` | 独立保留原直连渠道的认证、费用、任务与恢复能力，不能套用画布报价。 |
| 配音剪辑 | `/timeline.html?view=finishing` | 从当前选用视频整理顺序和音轨、保存时间轴；配音生成与字幕编辑尚未接通。 |
| 导出 | `/timeline.html?view=export` | 检查当前保存的时间轴，准备、执行本地 MP4 导出并下载；失败不损坏原片，不调用生成服务。 |
| 角色与场景 | `/resources.html?section=entities` | 查看当前有效实体和真实参考图；编辑链接首次展开并定位原实体编辑区。 |
| 风格库 | `/resources.html?section=style` | 查看15位导演、17个作品预设与规则来源；保存沿用原 revision API，保留兼容手册规则。 |
| 预算 | `/resources.html?section=budget` | 保存人民币制作预算计划，查看已保存的视频报价依据；预算不等于报价、余额或 Codex 用量上限。 |
| 设置 | `/resources.html?section=settings` | 展示实际配置边界及原有页面入口，不发放认证或消费批准。 |

原可选即梦文字页面 `/script.html` 和只读渠道记录 `/video-channel.html` 继续保留。即梦文字费用缺口不会阻止 Codex 文字创作。

## 版本、状态与消费边界

编辑、审阅、采用、素材替换、任务恢复继续使用原 API 与 revision 校验。采用候选前仍从当前存储核对输入、镜头、风格、知识库 Hash 和来源证据；上游变化使受影响结果需复核，旧稿、原始回执和文件保留。单纯重复点击“保存剧本并继续”或“确认分镜并继续”，在当前有效版本和内容均未改变时复用版本，不额外建版导致下游素材失效；修改后继续仍按原规则保存。

图片有历史选用记录，不代表当前仍通过检查。主预览只有当前审核、版本、文件完整性均有效时显示已选；被拒绝或过期的旧图保留预览并明确标记历史图和复核状态。视频下载成功、候选导入、人工检查与选用分别展示，成功任务的检查入口定位本任务候选。

本轮没有新增真实模型、图片、视频或配音调用，也没有新增付费服务。自动出图继续关闭，原失败任务、原图及 1/1 调用记录不重置；手工导出、导入继续可用。现有认证、预算与具体范围授权规则保留，未通过界面改版打开生产提交。未知费用继续显示待确认，人民币、积分与账号用量分别记录；70积分只沿用为既有方案的最大预估批准阈值，不是结算或平台硬限额。

本地导出只拼接已有、满足原媒体检查要求的视频。后处理静音保留原片并核验派生文件，不冒称模型原生无声。尚未接通的配音和字幕说明具体缺口，不用占位成功或测试媒体冒充 AI 成片。

```

node tests/ui-c-media-browser.mjs
```

浏览器检查使用独立测试项目和明确标注 TEST FIXTURE / NOT AI 的素材，覆盖1366×768、1440×900、导航、实际编辑保存、恢复、空白／失败／需复核状态及底部边界。隔离 runner 的结果不算真实模型生成。原有各页面浏览器回归仍保留；本轮实际执行结果及前后截图统一见[验收记录](ui-c-v10-acceptance.md)，不把历史通过当作当前自动通过。
