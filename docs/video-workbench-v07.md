# 即梦单镜头视频工作台0.6.0

当前流程：有效且人工检查、选用的分镜图 → 视频任务准备 → 参数与独立积分报价 → 原任务查询/下载 → 实际文件核验 → 视频候选 → 人工检查与选用。生产提交在本轮硬关闭，真实生成、画布同步、配音和剪辑未执行。自动出图仍关闭，没有扩展其hook机制。

## 启动和使用

设置原有`DATA_DIR`后运行`.\scripts\start.ps1 -Port 4320`，打开`http://127.0.0.1:4320/video.html`。升级继续使用原数据目录，不新建目录清零原1/1；同一数据目录只运行一个服务。Node.js22+，视频文件核验需要已安装FFmpeg/FFprobe，支持`FFMPEG_BIN`、`FFPROBE_BIN`绝对路径。

先在图片页检查并选用镜头图。视频页显示真实图片、Hash、图片及分镜版本；未经检查、未选用、拒绝或过期的图片不可准备。编辑模型、时长、分辨率、音频计划、运动提示词及积分预算后点击准备；只是本地保存，不上传或生成。修改未重新准备的参数时不允许提交旧任务。

本机直连CLI当前未登录，canvas已登录，分别展示；不会自动登录或改认证。费用未知时显示“费用待确认”，提交禁用。当前还受本轮生产门禁限制，即使前端参数、目录或环境变量变化也不会触发真实生成。

## 存储与输入绑定

- `src/video-store.mjs`：图片来源、不可变视频资产、人工检查及选择历史；视频绑定项目/镜头、来源分镜、图片版本/Hash、审核ID、选择ID、参考及知识库Hash。
- `src/video-jobs.mjs`：持久化任务、参数/快照/报价指纹、费用预留、提交意图、外部ID、查询及下载恢复。`data/video-jobs/`保存任务，`data/runtime/video-generation/`保存每次调用独立回执，任务内有索引。
- `data/video-files/`：新候选实际文件；`data/video-workspaces/`：候选、检查、选用历史。重做只新增任务与文件，不删除旧片。参考审核、分镜、图片、文件或输入变更使受影响候选需复核。
- 采用及提交前重新读取当前存储，核对图片实际文件Hash、当前审核、选用及来源分镜。迟到结果保留原输入绑定，可入过期候选，但不能覆盖当前要求。

## 任务恢复和费用

提交意图先落盘，重复准备/点击复用任务。同一任务并发只执行原操作；显式单镜重做才建立新尝试，并累计已预留积分费用。direct CLI没有公开客户端submit-id幂等参数，因此只能保证应用不主动重复；网络丢失外部ID时保留submission_unknown，不宣称服务端严格幂等。

拿到外部ID后，查询失败保留原状态与错误，继续查询原ID。下载失败仅重试原任务下载，不提交生成；原文件丢失可显式重新下载同一任务并核Hash，不能覆盖不同产物。取消/超时/重启保留原任务，无自动重提；本地取消不证明远端已取消或退款。

视频价格与文字报价分开。必须有本渠道/模型/参数适用的真实费用来源、条件及有效期，并在积分预算内；余额不作报价，未知不作免费。不编官方quoteId，不换算人民币。报价记录用于预留，实际扣费未返回仍为null。

## 文件、声音与画布边界

`src/video-media.mjs`使用实际FFprobe核验文件Hash、格式、正时长、尺寸和音轨；缺文件、文本假MP4或无效probe均失败。服务提供Range/HEAD预览，候选不自动检查/选用。播放器静音不等于文件无音轨。

当前CLI无原生静音flag。`provider_default`保留模型原始行为；`mute_derivative`仅是后续去音轨计划，原片有音轨时不能当无声版本选用。可选显式本地去轨函数只在测试素材上验收，本轮没有对生产文件执行派生或剪辑，没有暴露自动剪辑接口。

`src/dreamina-video.mjs`适配已核实help中的image2video/query_result及官方下载。canvas媒体上传/导入仅检查Schema和帮助，状态detected_not_verified/not_synced；直接视频成功不代表画布有媒体，文本节点不作导入证据。[CLI实际契约](jimeng-video-cli-v07.md)

注入的adapter无论是否自报fixture均视为隔离来源，不能提升为真实即梦结果。正式四岗位guard/账本仍未接入，`formalStageStatus=not_checked`，不发布正式制作包PASS。
