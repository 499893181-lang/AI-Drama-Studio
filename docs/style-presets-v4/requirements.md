# 风格预设 v4：固定22项与高清样图

本文件按用户2026-11-17最新明确要求整理，优先于历史文件中建议新增画风的描述。

## 范围

一级选项只取[22项清单](presets-22.json)，名称、视觉特征、适用题材按用户确认表保存。允许显示简短别名，但不能删除原名称或增加第23项。冷调、怀旧、游戏CG、敦煌等学习标签只用于细化现有预设、兼容组合或资料检索，不新增一级卡片。

## 页面

保留蓝白配色、六个一级导航、六个Agent子项、项目顶栏、独立右侧AI助手。风格页从上到下是标题、当前项目画风、全部风格及详情。全部22项在首次启动即存在，支持搜索、分类和点击分页，默认6个一页。未有图片的条目明确占位，不虚构生成成功。

风格卡片展示独立高清原图的缩略图、中文名称、可读特征和选用状态。点卡片预览；点击选用后保存到当前项目。预览不自动改设置。详情含人物、人景、场景、细节四种示例入口；没有对应资产时准确显示。规则说明普通用户可读，完整模板与来源可展开。自定义新增不改变22个内置项数量；用户自定义另分组计数。

## 高质量资产

样图逐张独立制作后再用于UI，不从整页界面图裁切冒充正式样图。先以同一原创成年人物、服装、雪林场景和大体机位对照电影写实、3D漫剧和水彩绘本，强调媒介、造型、材质和光影差异。预览资产是原创画风示例，不是项目角色或视频首帧，不自动把例图中的女性、服装和雪林带到其他项目。

每套预设最终可有四类原图：人物近景、人景中景、场景远景、材质/氛围细节。此次设计稿用少量独立样图说明质量方向，不能将其当作22套已生成验收。模型型号仅按实际回执记录，当前生成工具若不暴露型号，记录unknown，不冒称用户希望的Image 2.5。固定模型选型在软件已有图片服务中管理。

## 规则和传递

每种规则明确媒介、人物比例、线条与边缘、材料、主光和环境光、主辅色、构图与空间、景深和距离、后期强度、避免项。不能全部套用同一组电影/8K/超写实词。沿用学习资料中的具体规则，来源和验证状态分别保存。

项目保存预设ID、版本及有效快照。角色、场景、分镜图片和视频提交读取同一有效版本。按模型实际支持能力映射参考图用途与负面约束，不将资料板直接当首帧。切换画风保留旧稿、旧图、任务及原有恢复，只标记相关下游需复核。用户锁定的人物、年代、服装、时段、地点、空间和画幅优先。

## 验证

核对22个内置名称及别名唯一性、搜索/分页/分类不漏项、预览与选用分离、项目隔离、刷新和重启恢复、自定义与历史迁移。用隔离适配器捕获图片/视频的实际输入，证明规则与版本真正传入而非只保存名称。验证原图路径及来源、实际尺寸、静音/导出等既有能力不回退。1440×900、1366×768及窄屏能操作，助手不覆盖正文。只把实际执行的检查标为通过，样图真实风格符合性保留人工评价。
