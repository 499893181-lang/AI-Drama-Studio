## 三、四条参考分别教会我们什么

### 1. 人物质感需要逐项落实

第一条展示的是成年古装女性与雪林的不同处理。可观察的差异包括：
- 发丝是否分束、是否有少量自然碎发及合适的明暗。
- 毛领是否有长短、疏密和受光层次。
- 织物、金线、珠饰与皮肤是否具有不同的反光方式。
- 面部是自然摄影、较柔化的三维造型，还是绘画塑形。
- 背景是否与人物拥有同样的材质语言和光源关系。

这些细节按景别取舍：人物远景不能强求看清毛孔，水彩、黏土和油画也不能统一套用摄影皮肤描述。

### 2. 风格要在不同任务中成立

第二条覆盖：
暗黑哥特、未来科技、治愈日系、国风古韵、自然风光、动作大片、玄幻仙侠、写实摄影、影视广告、科幻悬疑。

可复用的做法是把每类拆成具体的场景、光源、材料和构图，再给出可比较的样例。
例如：
- 哥特场景依靠尖拱和高耸结构、冷月光与局部烛光、暗木及红丝绒等形成效果。
- 科技场景依靠金属和玻璃、几何空间、发光信息层与冷暖对比，不只是加入“未来”二字。
- 日系治愈场景中有大量写实摄影：窗光、木质环境、雨窗、热气和乡间道路，并不自动等于日漫。
- 自然画面通过地形尺度、雾层、水面反射、岩石与植物层次建立可读空间。
- 广告任务需要针对玻璃、液体、金属、皮肤或食物分别设计反射与焦点。

这些类别混合了媒介、题材、氛围和用途，软件不宜把它们全当成与“水彩、油画”完全相同的基础分类。

### 3. 场景要能服务叙事

第三条每套场景分为：
- 建立镜头：交代整体空间、主要建筑/地形、道路与人物尺度。
- 剧情镜头：提供人物行走、对话、交易或探索的位置与动线。
- 氛围镜头：选择有作用的局部细节，例如湿石、木箱、绳索、落叶、苔藓、光束和水面。

不能把“细腻”理解为所有角落都塞满细节。应让远景说明空间、中景承载行动、近景突出少量关键材质。
这套组织可用于制作风格样图，也可用于实际分镜。三张示例看起来相近，不等于它们已经满足同一场景的严格几何连续性。

### 4. 同构图对照有助于辨别真正的画风差异

第四条中值得落实的对照：
- 次世代游戏CG：三维体积、较精细的模型与材质表现。
- 二次元三维漫剧：较动画化的五官、柔化造型、相应的三维光照。
- 真人写实：摄影皮肤与真实物体的关系，同时抑制CG和卡通感。
- 油画：笔触、画布与绘画塑形，而非只加颗粒。
- 冷调电影：摄影基础上的色域、光比、粒度和景深组合。
- 敦煌壁画：矿物色、传统纹样和壁画表面语言。
- 新中式平涂：简化色块、清楚轮廓、留白与有限配色。
- 东方插画、淡彩韩漫、戏曲动画等：分别明确线条、造型概括、上色与装饰方式。

这些名称是创作者的分类。部分“胶片风”例图仍保留插画外观，因此应分别记录媒介与氛围，不把名称当成唯一标准。

## 四、程序中的预设怎样组织

建议保存三层信息，但普通用户仍然一键选择：

1. 基础画风
决定摄影、3D、二维动画、水彩、油画、水墨、平涂、纸艺、黏土等媒介及表现方法。

2. 可选的视觉组合
决定冷调、暖调、治愈、怀旧、哥特、科幻等氛围与摄影/后期处理。
不是所有组合都适合所有媒介；存在冲突时提示协调。

3. 项目内容与镜头
决定人物是谁、服装、年代、地点、时段、道具、空间布局、构图和动作。
切换画风不能擅自更改这些明确条件。

例如：
- 真人写实 + 冷调电影 + 雪林人物。
- 三维漫剧 + 温暖童话 + 老宅院落。
- 水墨写意 + 克制留白 + 湘江远景。

用户最新确定：一级风格严格固定为已给出的22项，具体名称与顺序以同目录presets-22.json为准。四条参考只补充现有预设的规则、例图与兼容的视觉组合；不新增一级卡片。
“电影写实”“游戏CG”“三维漫剧”等最易混淆的路线应先做对照测试。

## 五、每套预设至少写清十项

| 字段 | 需要具体回答的问题 |
|---|---|
| 基础媒介 | 看起来是摄影、模型渲染还是何种绘画？ |
| 人物造型 | 自然比例还是适度概括？面部如何表达？ |
| 线条与边缘 | 清楚墨线、柔和晕染、厚涂笔触还是无描边？ |
| 材料表现 | 皮肤、布料、木石、金属、纸张等如何不同？ |
| 主光与环境光 | 光从哪里来、软硬如何、哪些区域保留暗部？ |
| 主辅色 | 哪些颜色主导、饱和度和冷暖关系怎样？ |
| 构图与空间 | 主体位置、前中后景、观看焦点如何组织？ |
| 景深与距离 | 哪些细节要清楚、哪些区域可以简化或虚化？ |
| 可选后期 | 颗粒、暗角、晕光、雾等是否适用及强度？ |
| 避免项 | 针对该风格最常见的混淆和失真，保留什么、避免什么？ |

不得让全部风格都堆“8K、电影感、体积光、超写实”。
互斥介质要明确：摄影路线不能同时要求明显油画笔触；像素路线不能又要求平滑摄影皮肤。
所谓“负面约束”需按所选引擎真正支持的输入方式表达。

## 六、正式风格样图的制作标准

### 样图分工

每套预设最终可配四类独立原图：
1. 人物近景：检查造型、眼神、发丝、皮肤或绘画表达。
2. 人物与场景中景：检查服装、动作、人物与环境是否同画风。
3. 环境远景：检查建筑/地形尺度、空间层次和背景处理。
4. 材质或氛围细节：检查布料、木石、纸张、笔触、水面等。

以上是建议的完整资产结构，不表示现在要一次生成22×4张图片。
首页用其中一张做缩略图，详情可分别查看四张；缩略图从高清原图派生。

### 公平比较

先固定一份原创基准人物、服装、地点、姿态、机位与光源，测试最容易混淆的三个方向：
真人写实、游戏CG、三维漫剧。
允许各媒介有必要的造型概括，但人物关键辨识特征和项目内容保持可对应。
三类差异与细节达到要求后，再扩展油画、二维动画、水彩及其他预设。

不要把参考帖中的某位女性、白毛领服装或雪林直接固定到所有项目。
样图也不能只有“古装美女”一种题材，应检查其他年龄、人物类型与无人场景的适用性。

### 原图要求

- 独立生成完整画面，不在整张软件界面里顺带生成正式样图。
- 保留高清原图与实际尺寸，不能只把小图放大后称为高清。
- 正式原图默认不带风格标题、表格、边框、水印或未要求的书法文字。
- 细节符合媒介与观看距离，主体清楚，空间和光影可解释。
- 单张样图达到要求之后才用于界面和后续参考。
- 期望生图渠道为用户提出的Image 2.5方向；实际接入型号和可用性需要核对，生成记录必须填写真实调用型号，不能用其他模型出图后冒称Image 2.5。
- 参考帖中的提示词并未在本项目实测，不承诺跨工具复制即能得到相同效果。

## 七、原创提示词结构与示例

推荐结构：
项目主体与明确条件 → 当前画面瞬间 → 画风规则 → 构图和空间 → 光源及材料 → 色彩与后期 → 本镜头必须保留与避免项。

以下为本轮原创测试描述，未执行生成，不是对参考帖整段转录：

“制作一张真人摄影质感的原创人物样图。约26岁的中国女性，椭圆脸、平直眉、深棕色眼睛，黑发低盘，保留少量自然碎发。穿普通浅灰色棉麻上衣，站在晚秋老宅院落中，半身三分之二侧面，目光望向画面左侧，神情安静。人物位于画面右侧，近处旧木窗框形成轻微遮挡，中景可见青灰石墙，远处少量红叶与屋檐提供空间参照。

左前上方的柔和日光照亮脸颊和衣料，背光侧保留有层次的暗部。皮肤有自然色差和少量合理纹理，发丝分束但不过度锐利；棉麻在肩部和手臂处形成有重量的褶皱；木窗边缘有磨损，石墙有少量使用痕迹。焦点在眼睛，背景逐渐柔化但仍能辨认空间。主色为灰青、米白和旧木棕，少量红叶作为点缀，饱和度克制。

采用真实摄影的造型与材质表达。避免蜡质皮肤、过度磨皮、无来源光束、所有区域同样锐利、卡通大眼、三维模型感及明显绘画描边。不添加文字、边框或水印。”

要改为CG或三维漫剧，应替换媒介、造型、线条和材质段，同时调整对应避免项，保留主体、场景、构图与主要照明条件。
不能保留整套“真人摄影、杜绝CG”，再简单在末尾补“游戏CG风”。

## 八、从样图到视频的实际传递

选用预设后，软件应：
1. 保存项目风格与有效版本。
2. 用同一规则生成/整理角色与场景参考。
3. 结合分镜制作具体镜头提示词和必要首帧。
4. 根据视频模型能力传入参考素材与动态描述。
5. 保存任务当时的风格、模型、提示词和资产版本。
6. 检查人物、服装、材质、色调与空间是否在视频中漂移。

风格示例图、角色设定图、场景参考图与镜头首帧用途不同。
如果模型支持风格参考，才能以相应用途提交示例图；如果只接受首帧，应使用该镜头的实际画面，而不是通用示例或整张资料板。
动态提示词重点说明动作、运镜和需要维持的特征，按渠道能力适配；不保证只靠文字就能完全锁定风格。
