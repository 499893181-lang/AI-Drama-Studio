## 内容范围

- 每个主题包含50条不同抖音作品，共150个唯一作品ID，无类内或跨类重复。
- 采用视频片段抽看、图文部分页面及作品正文阅读；未将仅搜索标题计为学习，也未声称完整播放150条视频。

## 后续使用

先将提示词、镜头和风格意图拆成可编辑字段，再按具体模型能力转换参数。自动检查应覆盖人物与场景一致性、光源、空间、路径、焦点、时长和剪辑衔接；最终以样片和人工审阅为准。

本次仅归档研究资料，不代表这些规则、导演预设或媒体生成能力已接入工作台。第三方作品的完整图文、原片及登录资料未随本目录上传；来源链接用于追溯，不构成对第三方内容的再授权。
