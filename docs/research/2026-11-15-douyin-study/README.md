## 本轮新增方法

- 提示词：场景母版与俯视布局、多图参考职责、产品置入的比例和投影、角色与位置字母绑定。
- 运镜：人物注意目标与主体占比、对话机位和轴线、前后景焦点交接。摄影示范明确标为方法参考，未验证AI执行。
- 导演：以《敦刻尔克》分析目标、空间方向与危险信息；以《情书》分析帘幕遮挡、地点线索和跨时间状态对照。生图、运动和后期示例均为原创迁移练习。

## 筛选与证据边界

本轮共8条新视频，与既有164条均不重复。7条显示万赞以上；另一条为9026赞、9121收藏的专项编辑操作补充，单独注明实际数值，未将其称为万赞视频。热度只用于筛选，具体演示、观察内容和可用方法才是收录依据。

播放量仅记录页面公开的数据。本轮8条播放量均未公开，未用点赞、收藏、评论或分享推算。平台“万”缩写为近似展示值，换算数不代表精确到个位的计数或严格数学下界。

采用视频片段抽看、字幕与屏内提示词阅读、作品正文核对。原150条还包含图文部分页面；没有将标题列表计为学习，没有声称全部视频完整观看。本轮长篇拉片也按实际观察时间点标明范围，没有核实的声音或其他影片比较不作为实证。

导演册保留15位导演分析及原45套分层模板，并区分AI实操、原片分析、二创片段和艺术参考。另有1条HFA《黄土地》档案资料，不计入抖音来源数。短篇审美混剪若方法不足，不因高赞自动收录。
