## 第五轮三十条画面提示词学习总结

[阅读本轮总结与30条来源](round5-image-prompt-summary.md)。[结构化来源记录](round5-source-records.json)保留作者、作品链接、时长、点赞显示、观察时点、实际观察、原创迁移与证据边界；[12条规则与6套原创模板](round5-prompt-rules.json)供后续软件设计与小样对照使用，尚未接入软件或生成实测。

- 先写本镜要看清的信息；避开被遮挡的不可见细节，把多阶段动作拆成静帧与视频段。
- 构图落实为位置、占比、层次与视线；光影落实为来源、软硬、照亮对象和暗区内容。
- 材质依附于具体表面、接触和受力；细节向人物与关键道具集中，背景大面保留简洁区域。
- 每张参考图分配身份、服装、空间或色彩职责，单幅成图与多视图资产板分开。
- 局部修改分别写保留、改变与照明适配；删物体时同时检查投影和被遮挡背景。
- JSON、8K、焦距等文字不能代替接口能力；以版本对照和实际生成结果验收。

本轮30条与之前202条及本轮内部均按作品ID去重，无重复。25条显示万赞量级；5条专项补充为R5P02（9444赞）、R5P12（8881赞）、R5P25（7332赞）、R5P28（9042赞）、R5P30（3175赞）。万为近似展示，不解释为精确计数。播放量均未显示，未以互动数推算。

## 第四轮三十条学习总结

[先阅读本轮总结和来源索引](round4-previs-summary.md)，逐条证据另见[30条结构化记录](round4-source-records.json)。[规则与即梦映射JSON](round4-method-synthesis.json)供后续编排参考，不是厂商API请求。

- 人物路径、摄影机路径与注视目标分别描述，用起幅、中间地标和落幅确认方向。
- 白模保存空间与占位；表演动作锁另行设置，保留可编辑工程和参考视频。
- 明确角色多视图、场景、深度或动作参考各自职责，避免三视图误生多人、原背景串入或白模外观残留。
- 用动作相位、出入画方向、视线、道具和光色维持镜头衔接，再按叙事选择延长或组接。
- 用短片段的起中落对照检验结果，把无穿模、百分百一致等话术转成待验证检查项。

本轮30条与前172条及组间均无重复：25条页面显示万赞及以上，5条低赞专项或官方教程单列。例外为R4A01（2756赞）、R4A09（1695赞）、R4B02（2386赞）、R4B04（483赞）、R4C07（9731赞），均记录具体操作价值。初版来源不追溯标为万赞。
