## 一 从形容词转为画面关系

P01至P06、P09至P11与P19至P25反复出现相近思路：将模糊氛围拆为摄影、置景、光色与人物状态。它们并不能证明某套公式普遍最优，但足以支持我们先建立结构化编辑器，再用样片筛选规则。

| 输入层 | 需要回答的问题 | 可落地的描述 |
| --- | --- | --- |
| 叙事瞬间 | 刚发生什么 现在想做什么 | 老人刚放下电话，手仍搭在听筒上，目光停在空椅子处 |
| 人物与资产 | 谁 出场状态是什么 | 年龄、脸型与定妆图一致；衣领磨损，袖口有洗旧的折痕 |
| 空间与构图 | 谁在何处 前后景如何分布 | 人位于左三分之一，右侧留空；门框在前景，树影在后景 |
| 摄影与焦点 | 从哪里看 先看什么 | 平视中景，焦点落在握紧听筒的手与下垂肩部 |
| 光源与材质 | 光从哪里来 如何反射 | 窗外阴天侧光；旧木桌低光泽，棉围裙保留纤维纹理 |
| 色彩与后期 | 什么颜色主导 是否需要处理 | 灰青环境与少量暖灯光；保留暗部层次，轻微颗粒可选 |

写作顺序可采用“叙事瞬间 → 主体与动作 → 空间关系 → 机位景别 → 光源 → 材质 → 色彩 → 必须保留与避免项”。这是一种便于检查和复用的组织方式，并非模型必须接受的固定语法。

## 二 怎样让细节服务真实感

### 人物皮肤与表情

保留符合人物年龄、距离和光线的皮肤起伏、局部色差与少量自然不均匀。人物远景无需强行强调毛孔；年轻人物反复添加粗大毛孔、油亮汗水和深皱纹，可能改变年龄感。后半组人像资料对此存在不同主张，应通过样片决定细节强度。

表情要具体到可见部位。P17把同为笑意的状态区分为眉眼、嘴角、露齿和面肌变化；P23则用低头、肩部下沉与磨损衣物传达疲惫。优先描述一个主导状态及其外在表现，少量矛盾情绪可体现在动作与眼神之间，不让同一帧同时微笑、号哭和怒吼。

### 衣物 道具与环境的共同作用

把布料织纹、缝线、折痕、重量和磨损放在合理位置。旧围裙可以洗得发白，桌缘可以被手摸出较亮区域；这些痕迹应与年代、职业和使用方式吻合。风吹动头发时，也要考虑衣角、树叶和尘埃的方向；雨夜的衣物、地面与金属应共同响应潮湿。P19与P24提供了这类联动示例。

精美不等于把每个角落塞满细节。只安排少量能解释人物和场景的细节，其他区域保留简洁的明暗组织。近处需要触感，远处更多承担空间和叙事；画面处处同样锐利容易削弱焦点。

### 空间层次与尺度

前景负责遮挡、距离或视线引导；中景放叙事主体；后景说明地理、时代和光线来源。P05、P08、P20和P24分别通过峡谷、树林、废屋、燃烧建筑建立尺度与层次。大场面应加入可信的人物、门窗、车辆等参照，避免只写“巨大、史诗”。

连续短剧还需要场景锚点：门窗方向、树与台阶位置、室内外关系、人物惯常座位。把这些作为固定资产保存；单张图漂亮但门窗乱换，会直接影响后续视频与剪辑。

## 三 光影与色彩怎样写清楚

光线描述至少包括来源、方向、高低、软硬和影响对象。P22出现画面外高位侧逆光；P13的不同灯位带来不同情绪。与其写“唯美柔光”，可写“右侧窗外阴天散射光照亮半张脸，另一侧保留有层次的暗部，桌面只出现较弱反光”。

区分光源颜色和最终调色。P03的色温对照有助表达冷暖意图，但提示词里的数值不能视为精密摄影模拟。夜景里的暖灯、冷天空和人物肤色应有关系；全局套青橙色会掩盖场景自身差异。

摄影字段还要分清焦距、摄影机与主体的距离、景别以及感光介质规格。“35mm镜头”和“35mm胶片”不是同一项，IMAX也不应直接放进焦距栏。把目标画面占比和透视关系写清，再将数字作为辅助意图；不要用一串器材名称代替可观察的效果。

柔光、晕光、雾与颗粒都是选择项。P01的对照显示强扩散容易吞掉高光轮廓，P02讨论低饱和影调；这些方法适合部分风格，不是消除AI感的统一处方。不要为了“细腻”同时堆高锐化、重颗粒、强HDR和大面积柔焦。

| 教程常见词 | 本项目的处理方式 |
| --- | --- |
| 电影感 胶片感 | 拆成光比、色彩、颗粒、黑位和叙事构图，允许分别关闭 |
| 35mm f1.8 等数字 | 保留为语义参考，并优先写清视野、景深和焦点对象 |
| 真实HDR 虚幻引擎 | 视为不同视觉路线的候选标签；写实摄影不默认混合全部渲染词 |
| 体积光与雾 | 明确光源和介质位置，检查是否遮住主体或导致空间不连贯 |
| 次表面反射 | 不直接采用该表述；按实际目标区分表面反射与次表面散射概念 |

## 四 负面提示与约束写法

约束应对应具体失败现象，并说明应当保留的状态。例如“避免面部蜡质与过度磨皮，保留自然肤色与局部纹理”；“避免建筑悬空，墙体与地面有接触和遮挡关系”；“避免所有物体同样锐利，焦点保持在人物眼睛”。不要堆一整页无关缺陷词。

限制也可能互相冲突。“全身照”与“面部占满画面”、“自然低反差”与“强烈硬光黑色剪影”、“摄影写实”与“明显油画笔触”应在生成前提示选择。针对手部、文字或多人关系的问题，还应考虑改变构图、减少同时发生的动作、补充参考图或局部修改，而不只增加否定词。

软件内部保存结构化约束。目标接口支持独立负面参数时再映射；没有该入口时，将必要限制写入自然语言和验收清单。禁止项不能保证一定被遵守。

## 五 可填写的原创生图模板

以下模板是本项目根据学习记录重新设计的示例，不是从作者页面整段复制的提示词。方括号是待填写字段；生成静态图片时，只描述一个关键瞬间，不把连续五个动作塞进同一张图。

### 写实人物与生活细节

在[年代与地点]的[时间天气]，[人物及定妆图编号]刚刚[事件]，正在[单一动作]。以[景别与机位]观察，人物位于[画面位置]，视线落在[对象]。[前景物]轻微遮挡，[背景锚点]保留可辨识轮廓。[具体光源]从[方向]照亮[区域]，另一侧保留暗部细节。[两项与经历有关的材质细节]，肤色自然。主色为[色彩]，辅色为[色彩]。避免[本场景最常见两项失败]。

### 东方美学环境与人物关系

[季节时间]的[江岸或院落]，人物占画面[比例]，处于[方向和姿态]。近处为[石岸 草叶或门框材质]，中景为[人物与具体行为]，远处为[江面 山体或旧屋]。来自[方向]的[光源软硬]使[主体边缘与环境]产生明确关系。使用[主色]与少量[辅色]，空气远近层次自然。情绪通过[留白或人物间距离]呈现。避免漂浮建筑、舞台式补光及无关装饰。

### 夜雨空间

[街巷或房间]的夜雨，[主体]位于[位置]，正在[动作]。画内[灯或窗]是主要暖色光源，远处[天空或街道]保留较弱冷光。湿[材质]出现方向一致的局部反射，[衣物或金属]有与雨量匹配的潮湿细节。薄雾只集中在[区域]。焦点在[对象]，前后景仍有距离。避免整幅镜面地面、无来源光束和过强高光晕。

### 空场景资产

制作[场景编号]的无人环境参考图。明确[门窗 台阶 树 桌椅]的位置和比例，镜头朝[固定方向]。前中远景分别为[内容]，主要材质为[内容]，光源来自[方向]。保留[三个空间锚点]，可供后续镜头重复使用。不出现人物、字幕、摄影器材和新增出入口。

### 大场面中的小人物

[人物]处于画面[边缘或下方]，面对[巨大建筑或环境压力]。用[门窗 人群 车辆]提供尺度参照，明确二者的距离与接触地面。[事件]影响[烟尘 风向 材质反光]。主光来自[可解释来源]，人物仅保留[轮廓或部分面部]，观众先看见[叙事焦点]。避免只有巨大字眼而缺少比例关系。

## 六 从模板进入软件

建议分成意图层、资产层、生成层和验收层。意图层保存叙事目的与观看顺序；资产层保存角色、场景和道具；生成层为不同模型编译提示词；验收层保存本次图像的问题和下一次只改什么。导演名称和电影风格只是检索入口，不能替代上述字段。

| 数据组 | 建议字段 |
| --- | --- |
| 来源与状态 | 作品ID 作者 原始链接 访问日期 观察层级 观察笔记 未验证观点 |
| 镜头意图 | 事件瞬间 主要情绪 关系焦点 观众先看什么 |
| 画面规格 | 人物引用 场景引用 构图 景别 机位 焦点与景深 |
| 质感控制 | 光源方向软硬 主辅色 材质与使用痕迹 环境相互作用 |
| 适配与版本 | 目标模型 模型版本 自然语言 模型专属参数 禁止项 提示词版本 |
| 结果与反馈 | 素材ID 实际花费 生成次数 使用与否 问题类型 修改记录 |

跨模型时，保留画面意图，转换工具专属语法。教程中的模型版本、宽高比开关、风格化参数和参考图权重，只属于其对应工具与版本；软件需要能力表和转换规则。保存参考图来源、可使用范围及资产版本，不将作者完整图文或提示词批量复制进公共开源仓库。

## 七 第一轮生成验证方案

先选三个固定题材：日常人像、院落空场景和夜雨人物。每个题材锁定人物、构图、模型及可用的随机条件，比较基础提示词与单一改动版本，例如只改变皮肤强度、光源描述或前景层次。每组重复生成数次，记录全部结果，包括失败图。未生成样片之前，不将本手册的建议标记为已验证。

评价包含五项：叙事焦点是否清楚、人物与资产是否一致、空间与光影是否连贯、材质是否符合距离和环境、是否有明显生成缺陷。每项可按1至5分记录，由人工复核；同时统计可用率和每张可用图片的平均成本。单次偶然好图不能证明某个词有效，跨模型效果应分别记录。

软件首版可以先实现字段完整性与文字冲突检测，再加入图像问题标注和候选排序。自动审美只提供建议，最终是否使用由创作者决定。

### P06  AI场景没质感 是你没写空间和光影

### 二 提示词的最小可检验单位

把每个目标拆成可以在结果上回答“是否成立”的关系。例如“右侧窗光只照亮右半脸”“外套下摆在三视角都到膝上”“桌上仅一副碗筷”。“人物更高级”“光影拉满”无法独立验收。单次修改优先改变一类变量，保存原图和修改图，便于判断改善来自哪里。

真实感也要服从景别。脸部近景可检查局部肤色、唇纹与细小绒毛；全身与远景先检查比例、站立接触和服装重力。不能把“毛孔越多越真实”当成默认规则，更不能用强颗粒遮盖错位结构。

### 可见信息优先

先写当前机位确实能看到的主体、动作与物件，再补细节。被衣物、被子、桌面完全遮挡的特征通常应从当前图提示词移除。 验收：检查不可见属性是否诱导开洞、翻转物件或改变构图。 依据：R5P02、R5P09

### 一个明确的画面瞬间

将情绪改成可见状态，例如眼神停在桌沿、嘴角收紧、手仍握着电话。静态图选定一刻；先笑后哭、镜头推进等时间变化放在视频段。 验收：检查表情、手势与视线是否支持同一个情绪。 依据：R5P08、R5P17

### 构图写位置与比例

在景别之外写主体占画面多少、位于哪里、视线朝向，以及引导线或框架来自哪个物体。景深根据观众必须辨认的信息决定。 验收：检查头部切边、背景线穿头、主次混乱和必要信息被虚化。 依据：R5P12、R5P21、R5P23

## 光影材质与参考图控制

### 光线有来源与主次

先定主光源在何处，再写软硬、照亮对象和暗区保留内容。薄雾与尘埃只在场景需要光路可见时加入，不默认每张图都需要体积光。 验收：检查脸、衣服、道具与地面阴影是否对应同一主要光向。 依据：R5P01、R5P02、R5P16

### 材质细节依附表面

指定棉布、旧木、金属等具体表面及反光差异，写清接触、受力和磨损位置。材质变化与几何结构修改分开。 验收：检查物体是否浮空、布料褶皱是否符合动作、是否凭空长出装饰和零件。 依据：R5P03、R5P19、R5P28

### 细节按视觉重点分配

眼睛、关键道具等焦点保留必要纹理；大块墙面、天空和远景减少随机碎纹。画面是否精美取决于信息组织，不能只用细节数量衡量。 验收：检查重复纹理、锐化白边、油腻高光与整幅画面同等清晰。 依据：R5P13、R5P29、R5P30

### 真实感服从拍摄情境

选定手机随拍、自然窗光人像或棚拍等成像目标，再加入适量皮肤、衣物和环境细节。颗粒、失焦、磨损并非必需；身份特征不随意增加。 验收：检查是否把普通生活画面做成蜡像，或为去AI感而过度弄脏、模糊。 依据：R5P07、R5P18、R5P25

### 每张参考各有职责

参考分别负责身份、服装、空间、动作或色彩。明确继承与不继承项，当前镜头只引入必要资料。风格板、多视图和单幅成图需要不同输出要求。 验收：检查人脸串位、服装错配、额外人物、图板误生成拼图。 依据：R5P14、R5P15、R5P22

这些建议允许按题材调整。纪实院落、干净广告图和幻想城堡需要不同细节密度，不存在一套应无条件粘贴的质感后缀。

## 编辑流程与结果验收

### 局部编辑分保留与变化

写明改哪个对象、在哪个位置、允许改多大范围，以及周边什么必须保留。替换物体时允许照明适配；删除物体时处理影子及被挡背景。 验收：对照原图检查未修改区、透视比例、接触阴影与遮挡边界。 依据：R5P10、R5P11、R5P27

### 先验收资产再扩展镜头

场景母版应先确认门窗、桌椅、树与固定道具。俯视图和其他角度均是待审结果，不自动成为正确三维空间。图板选镜后单幅生成。 验收：对照固定地标、人数、位置与视线；发现错误先修母版再衍生。 依据：R5P14、R5P24、R5P26

### 提示词格式不等于控制能力

JSON用于存字段与比较版本，最终按模型接口能力输出自然语言或结构化请求。8K、焦距和PBR等字样只表达意图，实际尺寸及控制参数须由接口支持并验收。 验收：检查模型是否支持对应参考、负面词、比例、分辨率与编辑参数；不臆造API字段。 依据：R5P04、R5P05、R5P07、R5P28

### 每轮只检验一个变化

先修布局和物理关系，再处理光色，最后微调纹理。保留输入、模型版本、参考和输出，将一次有针对性的改动与基线比较。 验收：记录失败样本和人工评分；不能由作者精选图或一次命中推断成功率。 依据：R5P09、R5P29、R5P30
