# AI短剧可选模型与高清质量评估

日期：2026-11-17（Asia/Shanghai）。范围：方案调研与开发要求；没有在用户电脑部署模型、配置真实密钥或开展付费出片。用户以8GB显存举例，并未提供本人电脑硬件数据。

## 1. 最终产品结构：文字、图片、视频分别选择

用户最新澄清：候选可以很多，但无需全部安装、同时接入或同时运行。先调查真实能力、成本和硬件，再将验证可用的渠道接入软件，让使用者自由组合。

| 独立选择 | 承担任务 | 目前可研究的候选 |
| --- | --- | --- |
| 文字模型 | 梗概扩写、剧本、按时间分段的详细分镜词、助手修改建议 | DeepSeek API、OpenAI文本API；现有本机Codex保留为独立账号方式 |
| 图片模型 | 人物正侧背三视图与细节综合图、每片段一张四宫格视觉参考、必要首尾帧 | 豆包对应的Seedream图像API、OpenAI GPT Image；OpenAI GPT Image 2.5（用户已明确指ChatGPT中的生图功能） |
| 视频模型 | 文字/参考资料转动态视频、首尾帧过渡、必要分段或延长 | Seedance 2.5、MiniMax H3、Wan 3.0的已验证可用渠道 |
| 本地运行设置 | 承载所选本地模型与工作流 | ComfyUI或WanGP，作为运行方式，不与模型名混成同一层级 |

示例组合（仅表示架构可组织，不表示已联通验收）：
- DeepSeek文字 → Seedream图片 → Seedance 2.5云视频。
- OpenAI文字 → 独立图片模型 → MiniMax H3，经选定的ComfyUI或WanGP工作流生成。
- DeepSeek文字 → Seedream图片 → Wan 3.0云视频；使用前验证地域、账号开通与参数。

用户只需配置选中的服务。后台可按项目保存默认组合，任务保存实际模型、版本、运行方式与输入快照。换模型保留原稿、参考图和历史；有兼容性影响的后续内容提示复核。普通讨论不改稿，模型失败不静默切换另一收费服务。

## 2. 几个名称必须按实际能力对应

### DeepSeek文字API不等于原生生图API

当前官方模型列表的输出模态为text；支持输入图片进行理解，也不等于输出生成图片。可以由DeepSeek写生图提示词，再交给选定的图像服务执行。

DeepSeek官方Janus/Janus-Pro属于独立的多模态生成项目。若以后研究这条生图路线，需要单独部署、单独检查质量与硬件，不能只配置同一个DeepSeek聊天API Key就宣称已能生图。

依据：
- [DeepSeek官方模型元数据](https://api-docs.deepseek.com/api/list-models/)
- [DeepSeek官方Janus仓库](https://github.com/deepseek-ai/Janus)

### 豆包图片与OpenAI图片

豆包是产品/品牌名，接图像API应记录实际Seedream模型ID。火山官方图像教程已提供Seedream系列的文生图、图像编辑与多参考图能力。是否能稳定画好三视图和细节板还需本项目验证。

OpenAI的文字模型与GPT Image图像能力分别配置。用户已明确“image 2.5 / Imagine 2.5”指ChatGPT中的OpenAI生图功能，图片候选按GPT Image 2.5系列记录。API接入时核实具体型号与账户准入，不把ChatGPT产品内使用直接等同于软件已获得API授权。

依据：
- [火山方舟图片生成教程](https://console.volcengine.com/ark/region:cn-beijing/docs/image-generation-tutorial)
- [火山图像API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh)
- [OpenAI图像生成工具](https://developers.openai.com/api/docs/guides/tools-image-generation)

### WanGP、Wan 3.0不是同一产品版本

WanGP是运行应用，Wan是模型系列。软件版本号与模型版本号独立。当前核实Wan 3.0的官方可接入路径为百炼API，不能由WanGP支持Wan2.2推断Wan3.0已能通过它本地运行。未核实的权重、适配插件或自称官方的仓库不能提前标记为本地可用。

[阿里云官方Wan 3.0视频指南](https://help.aliyun.com/zh/model-studio/wan3-video-generation-guide)

## 3. 四项重点对比：优势、配置和本项目适配

以下“适配判断”是依据文档的工程分析，不是同提示词实际画质排名。

| 项目 | 定位与优势 | 配置/输出边界 | 对本项目要求的判断 |
| --- | --- | --- | --- |
| ComfyUI | 通用模型运行工具和可保存的工作流；有任务API，适合由我们自己的简洁界面调用 | 显存与分辨率由实际模型、权重精度和工作流决定；工具本身没有统一“只支持480P”的上限 | 适合做本地/自建后台；人物参考、运镜和时长必须落实到具体模型与工作流 |
| WanGP | 集成模型的生成应用；有内存优化、参考与生成流程，可做本地候选后台 | 不同模型配置差异大；低显存能启动不代表高清长片生成速度可接受 | 适合研究低显存方案与批量候选；不能承诺任意模型在8GB上都能高质量出片 |
| Seedance 2.5标准版 | 云端视频模型；支持参考素材、首尾帧、编辑/延长与最长30秒输出 | API列出1080p及4K输出；普通客户端不承担生成显卡负载；按服务规则付费 | 文档能力覆盖30秒叙事、人物/场景参考及高清输出，值得作为高质量云端候选；实际细节、连续性和收费待实测 |
| MiniMax H3 | 有开放权重的模型；FL2VA处理文字/首尾帧，Ref2VA处理多模态参考；可同时生成音画 | 本地H3-Base默认短边768p，单次4–15秒；云端完整工作流包含上下文处理和2K重新生成，不能当成一份权重全覆盖 | 适合研究本地人物/场景参考；30秒需分段或续接，不能承诺与云端完整流程同等效果 |

补充：Wan 3.0官方API支持最长30秒、首尾帧/参考生成与编辑，当前所核对指南列出的输出档位为480P、720P、1080P；不据此宣传它已提供原生4K本地生成。

重要版本区别：Seedance 2.5标准版列有1080p/4K；2.5 flash仅列480p/720p。若最终以高分辨率为目标，不能将两者的价格与规格混用。

## 4. 8GB显存不是480P的硬性天花板

两条可定位的反例：
1. ComfyUI官方Wan2.2教程说明，5B版本可借助原生offloading在8GB显存运行；这仅适用于对应模型/方案，不是对所有工作流的承诺。
2. WanGP维护者在2026-01-13的LTX-2优化记录中报告过8GB生成720p、10秒视频的配置。这是特定模型与优化的作者报告，不是本项目在任意8GB电脑上的实测。该记录也提示，能输出4K尺寸不等于视觉结果就好。

8GB能运行某些方案不代表全部参数都适用。显卡架构、显存、系统RAM、SSD、权重大小、量化、时长、分辨率、参考数量、加载与卸载方式都会影响能否跑、速度和结果。

| 情况 | 本项目建议如何处理 |
| --- | --- |
| 客户端无合适独显或仅8GB | 保留文本和编辑能力；小样可测试，正式高质量视频允许选择云API/云GPU，不让客户端硬件强制决定最终画质 |
| 本地16–24GB显存 | 作为较有余量的候选配置区间，仍按实际模型验证，不保证任意4K长镜头都能运行 |
| H3本地部署 | 官方汇总的社区参考点包含12GB量化低分辨率方案；并建议考虑32–64GB系统RAM。不要将它写成统一最低配置 |
| 云端生成 | 用户本机无需承载生成模型；由服务端配置决定能力，用户仍需网络、存储和播放环境 |

[WanGP官方历史优化记录](https://github.com/deepbeepmeep/WanGP/blob/main/docs/CHANGELOG.md)

## 5. 用户的质量要求

用户明确要求：非常高清，人物刻画细腻真实，运镜有质量，避免粗糙低质感。当前未确认最终是1080p还是4K交付，因此软件保留两档，不擅自把480P/720P定为成片目标。

需要分别记录：
- 模型实际生成的分辨率与媒体文件像素；
- 是否经过超分、重新生成、补帧或压缩，各自参数和产物；
- 人物五官、表情、发丝/衣料细节、手部与身体结构；
- 镜头运动路径、速度、焦点与主体动作是否符合文本；
- 连续播放时的闪烁、融化、面貌漂移、衣物/空间改变与动作衔接。

不能只把低清视频放大到4K尺寸就报告“超高清质量验收通过”；接口返回4K选项也不能独立证明细节、人物和镜头都达标。

## 6. 与用户分镜方案结合

继续保留：故事梗概扩写 → 详细文字分镜（按0–5秒、5–10秒等覆盖片段）→ 人工审核 → 人物综合图和每片段一张四宫格视觉参考 → 选定模型生成视频。

人物卡、三视图、局部细节和四宫格是参考资产，不强制为每个小时间段单独生图。对接受拼图/多参考的模型使用对应入口；不支持的模型需选择单幅或适配，避免成片呈拼图。

不同渠道的首尾帧模式与多模态参考模式可能互斥。Seedance和Wan 3.0文档均列有这类限制，软件应在提交前检查，不能在同一请求里盲目塞所有资料。负面提示按目标接口映射；只有自然语言入口时按可读约束编译，不能假造独立字段支持。

所有一致性和时间节点仍需检查；文字中写了限制不代表模型保证执行。

## 7. 费用与验证顺序

已有云GPU、万相托管API的公开价格示例见[需求记录](requirements-2026-11-17.md)。它们不是Seedance 2.5、Wan 3.0或H3当前账号的报价，也不是同画质成本对比。

建议先用一个5–10秒的统一测试片段，涵盖脸部/手部细节、简单运镜和固定场景；再验证30秒时间安排、跨镜人物一致性和目标清晰度。保留失败候选，按实际可用素材计算总费用，而不是只计算最终选用的一条。

只研究被选择的组合，完成认证和最小连接后再测质量；不为比较自动购买硬件、充值或同时提交全部渠道。
