# 分镜图片工作台（软件0.4.0）

基线为 `f1e2c382bcb9c66f0543b5d15f8ba92dc8aa31c3`，独立分支 `codex/image-workbench-v05-20261115`。原立项、文字候选、独立审阅与即梦文字页面保留。本页从已保存分镜管理实际图片文件，不发布正式四岗位制作包。

```powershell
# 独立worktree、独立data，与原4317/4318服务并存
.\scripts\start.ps1 -Port 4319
```

打开 `http://127.0.0.1:4319/images.html`，选择项目。先在文字与分镜工作台保存剧本、实体及分镜版本，再为人物、场景或镜头导入图片。每个镜头显示画面提示词、导演规则和实体版本引用；人物定妆图、场景图与分镜图分开保存。上传不会自动选用：先预览实际文件、核对声明和画面，再记录人工检查并选用。

## 文件、版本与来源

只接受实际PNG、JPEG、静态WebP，服务端按文件字节核查格式、尺寸与结构，记录SHA256、字节数及来源声明。上限20MB、单边8192像素、总像素2500万；不接受SVG、动画、伪扩展名或超限文件。PNG检查块CRC和解压扫描行；JPEG/WebP检查段/帧结构。这些检查不代替完整视觉解码与人工内容检查，浏览器预览仍须核对。

图片文件写入后不覆盖。单镜头换图追加版本和选用历史，原图、旧选择和检查记录保留；不会删除全部镜头重建。输入、实体、知识库、分镜或所选参考图改变后，受影响版本显示需复核，选择前服务端重新读取当前目标和参考Hash。旧图仍可查看，不能悄悄变成当前合格稿。

来源平台是用户声明，上传的ChatGPT图片不冒充服务端核验。验收图片明确显示 `TEST FIXTURE / NOT AI`，并记录 `source.kind=test`，不作为AI生成成功证据。

## 手工ChatGPT任务包

选定镜头及当前人物/场景参考版本，生成并下载任务包。JSON包含实际提示词、规则、锁、稳定实体ID/版本、输入快照和参考清单；ZIP额外包含 `prompt.txt`、`manifest.json` 和实际参考图文件。仅引用但未选择附加的素材不在ZIP内。

`includedInBundle=true`只表示文件确实包含在ZIP中，`attached=false`表示软件尚未向ChatGPT发送。下载不等于模型已读。用户需在官网主动上传实际参考图及提示词，再将生成结果保存到本机并导回对应镜头；可关联原任务包追溯输入。无任务包的手工上传按当前输入绑定，并明确未验证模型实际输入。旧包返回的图片保留旧绑定，显示需复核，不以当前Hash冒充新输入。

图像自动调用与费用证据见[工具核查](image-tools-check.md)。当前软件只提供手工模式，费用显示待确认，不将登录或订阅当成免费API。

## 实体来源保护

模型自报 `source=user` 不再直接成为用户事实。新实体如从真实输入提取，可提供具体字段路径、原文起止位置、摘录及输入快照Hash；服务端独立核对。确定性检查使用保守的逐字证据门槛，不宣称自动理解语义。AI补充和来源待确认分别显示，原始描述、自报来源与原文均保留。

来源侧录绑定输入快照与实体内容Hash，采用及下游重新核对。旧记录缺证据时显示待确认，不回填假证据。明确确认保存待确认候选只代表允许保留该版本，不会把待确认升级为用户锁。用户真正新建或修改的实体输入另有服务端人工编辑记录；相同数组重新保存不会洗白模型声明。

## 验证与数据

```powershell
node --test tests/*.test.mjs
node tests/image-browser-smoke.mjs
node tests/creative-browser-smoke.mjs
node tests/script-browser-smoke.mjs
```

图片索引、版本、检查、选用历史和任务包保存在 `data/image-workspaces/`，实际原图在 `data/image-files/<项目ID>/`；来源证据与输入快照保存在原创作工作区、任务和不可变版本内。[独立验收](image-workbench-acceptance.md)分开记录隔离测试、真实浏览器与明确测试图片。原个人data、认证、任务与历史版本未迁移，Git不包含这些文件。本轮不提交即梦画布、视频、配音或剪辑任务；正式guard、15份生产文件和账本仍未接入，人工选图不等于正式制作包或媒体成片PASS。

独立测试服务可运行 `node scripts/verify-image-local.mjs --run-test` 建立测试项目；它只导入标注测试PNG，不提交模型或媒体任务。重启同一测试服务后用 `--restore` 检查原文件Hash和历史，不重复创建项目。脚本默认4319，必须使用独立data；不可把它当作生产作品或真实AI生成验收。
