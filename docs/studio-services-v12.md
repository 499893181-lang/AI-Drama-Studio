# 多渠道、六 Agent、声音与剪辑工作台 v12

2026-11-17。需求基线 `codex/product-requirements-20261117` / `1e70fdaf2ed82f768ee3d02fe1d56b40d51b94e1`，实施分支 `codex/studio-services-voice-editing-20261117`。包含 v11 全部功能；历史 PR 不合并。本文件优先于旧需求中四 Agent、三类服务、C 版双侧栏及即梦新建任务的描述。

## 使用

用 Windows PowerShell 在工程目录执行 `./scripts/start.ps1 -Port 4321`，或 `node src/server.mjs`。已有数据通过原来的 `DATA_DIR` 指定；不要为重置调用额度更换治理根。无需 npm 安装前端依赖。`node scripts/check-ui.mjs` 检查真实页面；`node --test tests/*.test.mjs` 运行回归。

左栏一级入口为 AI服务配置、通用、风格预设、导演风格预设、Agent配置、存储位置。Agent 下为剧本、角色与场景、分镜拆解、提示词、配音与声音、剪辑与导出（剪映）。顶部切换项目、新建故事；视频属于提示词下一步，不另加 Agent。界面中英文与浅深主题随本机保存，作品正文和历史回执不翻译。

1. 在故事页保存构思，在剧本页生成或编辑并一次确认。四标签、场景分页、原候选、版本及独立检查保留。
2. 角色与场景页左右并列编辑视觉候选；来源不足仍待确认。保存后可手工导入综合人物板、场景四宫格，检查后选用；参考板不自动成为视频首帧。图片高级入口可本地裁切，保留原图、裁切范围及双方 Hash，新图仍待人工检查。
3. 分镜页编辑连续时间段的静态画面、动态摄影、声音意图，选用导演及作品规则。画风单独保存，十五位导演、十七个作品级预设及三本手册继续复用 `knowledge/creative`，未勾选案例规则不自动启用。
4. 提示词页编译保存当前包，查看逐镜实际提示词及引用；统一视频子页核对当前首帧、渠道参数、任务及费用。即梦旧页只保留历史、原 ID 查询、下载及人工版本。新建与提交在服务端也关闭。
5. 声音页先保存人物/年龄声音卡与台词，逐句分页编辑表演要求。音频导入、检查、选用分开，旧候选保留。意图、真正发送参数和未支持项分开保存；没有音频不画假波形，不显示可试听成功。
6. 剪辑页只引用人工选用的现存视频/声音，编辑微秒级裁切、位置、字幕、对白/BGM/音效、音量、淡入淡出和淡化转场。FFmpeg 导出是保留原片的新派生；原 v1 整片拼接仍在次级入口。剪映新草稿、打开、自动导出分别记录。

## 服务与执行边界

四类服务独立全局默认、项目继承或覆盖；没有默认即梦或付费备用。服务配置保存实际模型、参数、费用来源和版本。凭据用当前用户 Windows DPAPI，后端解密；不复制 Codex 凭据或 Cookie。

本轮后台真实生成门保持关闭，前端不能解除。配置、无消费检测、准备、查询旧任务和本地素材加工可用。云端请求、授权与回执通过隔离传输验证；本轮没有真实文字、图片、视频或语音生成。后续开启运行须另行批准范围和逐任务预算，不能用本轮测试批准替代。账号目录成功只代表目录连接，不能升级为模型生成资格。

| 类别 | 实现与限制 |
|---|---|
| 文字 | DeepSeek/OpenAI Responses、本机 Codex、独立官方 SIWC 文字 OAuth；所有文字岗位共用解析器和原生终态验证。SIWC 未在真实账号授权；网页订阅不授权图片 API。 |
| 图片 | GPT Image 2.5 Sunburst/Flare，实际 multipart 参考；Seedream 图像请求与候选导入；现有手工导出/导入保留。 |
| 视频 | 百炼 Wan 3、方舟 Seedance 2.5 标准/flash、MiniMax H3 的准备、原 ID 查询、下载及候选桥接。参数按实际型号限制，URL 参考核对取得字节 Hash，但服务端是否使用未返回则未知。 |
| 本地运行 | ComfyUI/WanGP 与模型分开；检测可执行文件、权重和工作流，未验证组合不可执行。未自动下载模型或启动推理。 |
| 声音 | MiniMax/ElevenLabs 同步音频契约、模型参数裁剪及独立音频解码；IndexTTS/Qwen3-TTS 需真实已核验本地 runner，未部署不显示就绪。 |
| 剪映 | 锁定 pyJianYingDraft 0.3.1，在隔离 Python 环境创建唯一新草稿。本机 11.8 打开/渲染未验收，自动导出关闭，不调用未核实的随包补丁命令。 |

精确契约、官方来源及隔离范围见[服务说明](services-v12-contracts.md)和[声音/剪辑说明](voice-editing-v12.md)。没有把测试回执字段当成官方必返字段，也没有编造免费、汇率、quoteId 或服务端附件使用回执。

## 版本与恢复

旧任务快照、Hash、失败、回执及来源保留原规则。新文字绑定策略 2 将并发 revision 与语义输入分开；项目名称/预算不改写剧本，正文/实际引用内容改变才使相应依赖过期。来源设定不因采用变为用户事实。人物场景视觉版依赖确认剧本与实体，镜头仍依赖分镜及实际参考审核。

通用助手按人物、场景、分镜、提示词、声音稿、剪辑计划或界面设置分派应用。设置只允许语言和外观，不能修改凭据或消费授权。当前目标及依赖 Hash 在应用前重读；先存应用意图，再追加域版本，崩溃后按 assistantTurnId 恢复。未被后续编辑改变的应用可撤销为另一新版本；原稿和应用历史保留。剧本沿用原先独立助手与原子确认机制。

项目位置索引只为新项目选择新目录，不自动搬迁旧项目。项目元数据/素材经统一文件解析器定位；任务、签名、预算、治理根和原图片 1/1 不跟随默认项目目录重建。启动后将原治理目录位置记在 Git 忽略的 `.local/studio-runtime.json`；下一次不传 DATA_DIR 也复用原目录，目录缺失或另指定空治理根时停止启动，避免重建账本。取消目录选择无写入，保存前实际写入探针。回滚代码时保留 `project-locations.json` 和新增目录，恢复新项目应使用支持索引的版本；不得删除目录当作回滚。

媒体任务先存稳定 submitId 与跨实例提交标记。同步未知结果无任务 ID 不自动 POST，异步只查原 ID；下载失败只恢复下载；迟到结果绑定原输入且不自动采用。声音未知结果即使迟到音频保留，也不会追改原失败为成功。正式四岗位 guard 与账本继续 `not_checked`，这里的“已完成”仅指当前资料或人工选用状态。
