# AI短剧软件需求补充：文字模型、分镜资料与视频渠道

记录日期：2026-11-17（Asia/Shanghai）。根据本轮用户讨论整理，供后续开发复用。本文件是需求与待验证方案，不表示已完成API接通、工具安装或真实视频验收。此前确认的C版完整左栏、蓝白留白、点击分页与右侧AI助手继续沿用。

## 一、文字模型：先接DeepSeek

- 首先尝试DeepSeek官方API，用于故事扩写、剧本、分镜文字与AI助手。
- 保留后续可选择豆包、OpenAI等文字模型的设计空间；现有本机Codex通道可以保留。
- 模型切换不能删除既有稿件；任务需记录实际服务商、模型与用量，不能将订阅额度等同于所有外部用户的免费API。
- 密钥由使用方在安全的本机/服务端配置，不写入项目正文、Git或聊天。当前没有本次真实DeepSeek调用成功证据。

## 二、核心流程与资料形式

以下按用户最新明确的Agent列表顺序记录；用户在对应页面点击切换，各步骤保留人工审阅与修改。

1. **剧本**：输入故事梗概，调用已选文字API扩写为完整故事，用户核实、修改并确认。
2. **角色与场景提取**：从已确认的剧本提取角色与场景，在同一页面左右两栏展示。角色栏按人物分别展示描述与综合设定图；每个人物一张大图包含正面、侧面、背面三视图及头部、手部等必要细节特写，保持同一人物、年龄、服装与画风。场景栏制作四宫格视觉参考图，统一空间布局、色调、光线与画风。两栏调用前面选定的图片API；分镜确定后关联相应人物、场景与时间点。
3. **分镜拆解**：调用已选文字API，结合已确认剧本、人物场景设定、画风和导演风格，详细拆解场景、人物动作与运镜。每个片段有总时长，按连续时间段展开，例如0–5秒、5–10秒，直到完整覆盖片段；30秒是用户举例。主要交付为详细文字分镜，不要求逐帧或每个五秒段都生成一张图。
4. **提示词**：独立页面整理限定提示词，供后续视频生成使用。沿用此前确定的固定场景与空间布局、人物、服装、道具、画风、色调和光线约束，明确允许的变化与衔接，并附相关负面提示词；结合连续时间段分镜使用。用户还可继续补充具体限定内容。

角色描述保留姓名/身份、年龄、外貌与可识别特征、服装等信息。场景范例可关联对应分镜画面/时间点；用户以开头画面、0.5秒举例，不据此为所有片段固定同一时间点。

实现边界：固定条件、参考图和负面词用于减少漂移，不宣称保证零随机变化。四宫格/三视图是资料板；根据视频模型能力选择单幅、拆分视图或参考输入，不能未经适配直接当视频首帧，导致成片也呈现拼图。时间标注是导演意图，模型是否严格执行须实际检查。模型不支持单次30秒时，应明确展示分段生成与拼接安排。参考图实际生成需要图像渠道，文字模型返回提示词不等同于图像已生成。

## 三、视频生成保留可选择的候选后台

用户最新澄清：先调研并验证候选，再让使用者分别选择文字、图片、视频服务，自由组合。ComfyUI和WanGP都在本地运行工具候选范围，但不要求所有用户安装两套，也不同时运行所有模型。详细调研见[模型选项与高清质量评估](model-options-and-quality-2026-11-17.md)。

- 它们是两个独立的模型运行/工作流工具，不是同一个模型，也不是安装一份skill就自动拥有视频能力。
- 适配层可封装成可调用任务；每次只向用户选定的后台提交，不默认同时生成两份或同时占用显存。
- 本地模式由运行视频模型的电脑提供算力；实际显存需求取决于模型、量化、分辨率、时长和工作流，不按工具名称统一承诺门槛。
- 云端模式在远程服务运行，普通客户端电脑主要负责编辑、上传参考、提交任务和查看结果；仍需负担云算力或托管API费用。
- 界面区分未安装、未启动、未下载模型、硬件/功能不满足、服务可用与真实生成成功；显示具体原因，不用下拉选项冒充已接通。
- 首帧/首尾帧控制通常需要实际图片；哪些模型接受首尾帧、人物参考、多个时间节点需分别核实。纯文字描述不等同于图像锚定。
- 只为选定的本地模型配置需要的运行工具；若安装多套，隔离依赖和服务。可兼容的模型文件再考虑复用，不承诺所有权重可共享。
- 尚未检查用户电脑型号，也未部署这两套工具或运行成片测试。

## 五、文字、图片、视频独立组合与高清要求

- 文字候选包括DeepSeek、OpenAI；图片候选包括豆包所用的Seedream、独立图像模型；视频候选包括已验证渠道的Wan 3.0、Seedance 2.5、MiniMax H3等。候选不等于已经接入。
- DeepSeek当前官方文字API不能直接当作生图API；其Janus系列是另一个需要单独研究的部署项目。用户已澄清“image 2.5 / Imagine 2.5”指ChatGPT中的OpenAI图像生成功能；图片候选按GPT Image 2.5系列记录，具体API型号另行验证，不再作为厂商待确认项。
- 用户追求高清、人物细腻真实、运镜有质量。8GB显存不是480P的统一上限，但不同模型、量化、时长、参考素材与工作流需分别检查。
- 记录原始生成和超分/重新生成后的分辨率；不能仅凭放大后的像素尺寸报告高质量通过。
- 当前阶段先完成调研和组合设计，再按选择安装、配置及测试。没有要求一次性接入或付费试跑所有渠道。

## 六、左侧导航与Agent工作区补充

左侧六个入口依次如下，均为点击切换的独立设置页面：

| 顺序 | 入口 | 内容 |
| --- | --- | --- |
| 1 | AI服务配置 | 分别选择文字、图片、视频API，并配置所选服务的接入信息；三种服务独立组合。 |
| 2 | 通用 | 软件界面中文/英文切换，并保留此前要求的浅色/深色外观切换。本轮已澄清此处指软件界面语言，不能仅实现成生成内容语言。 |
| 3 | 风格预设 | 3D漫剧、水彩、绘本、美式漫画、国风、2.5D等；整理已有GitHub学习资料形成预设库，人物、场景和视频共用选定画风。 |
| 4 | 导演风格预设 | 选择自定义风格或已有十五位导演的风格预设；与画风作为独立维度。 |
| 5 | Agent配置 | 进入后展示下述四项Agent列表。 |
| 6 | 存储位置 | 由使用者选择项目保存在自己电脑上的哪个文件夹，并显示所选保存路径。 |

Agent配置内的列表顺序单独确定为：

| 顺序 | Agent项 | 界面与输出 |
| --- | --- | --- |
| 1 | 剧本 | 故事梗概输入、所选文字API扩写、人工确认。 |
| 2 | 角色与场景 | 左右两栏：每个角色独立的描述、三视图及局部细节；场景描述与四宫格。调用已选图片API。 |
| 3 | 分镜拆解 | 详细到0–5秒、5–10秒等连续时段的场景、动作和运镜，结合已选导演风格。 |
| 4 | 提示词 | 固定设定与其他限定提示词，供后续生成视频使用。 |

不得将左侧设置菜单与Agent内部流程混为同一层级；不得把分镜拆解排到角色与场景提取之前。 最新层级修正：左侧六项作为一级入口；展开Agent配置后，以缩进、连接线和较小字号显示四项二级菜单；角色与场景页内再左右并列角色设定与场景预设。文字、图片、视频接口选择放入AI服务配置页；Agent内容区不重复放置服务选择器或横向四步导航。用户本轮要求先保留已选蓝白留白风格，制作界面图片查看层级和功能理解，再继续讨论。效果图仅为界面设计预览，人物、场景和路径可用示意内容，不能冒充真实API生成或实际目录保存成功。

其中OpenAI图像生成功能是图片服务候选，与文字模型、视频模型独立选择；具体API型号与接入仍需验证。本文件记录需求与设计，不表示真实界面已经完成修改。
