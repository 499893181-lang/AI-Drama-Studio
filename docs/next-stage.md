# 后续开发任务（0.2.0后）

第二阶段适配与隔离验证见[stage2.md](stage2.md)。jimeng-novel认证已成功，但本轮没有提交真实剧本或媒体。

1. **真实剧本业务验收**：由用户选择真实画布/空间，完成绑定；取得适用于script任务的可核验费用与预算依据。当前费用未知，默认不能提交。之后再对已确认输入执行一次大纲/单集，核对原回执、完整正文和独立审阅。
2. **Agent改稿**：继续核对官方专用修改/诊断契约。当前没有已确认的原位Agent改稿API，不使用文本节点更新冒充；现有人工另存与不可变历史继续保留。
3. **即梦分镜→Codex检查**：验证实际分镜创作接口与输入输出，再建立人物/场景/道具ID、起终态、空间与声音时间线及审阅失效规则。
4. **画风与预算**：从真实价格/积分来源区分计划、估价、确认和实际费用，不能把余额或节点估价套到其他业务。
5. **画布和无配音视频**：保留提交ID及幂等恢复，确认音轨控制，不自动开启媒体生成。
6. **配音、字幕、剪辑和成片导出**：只在真实媒体产生后验证实测时长、授权、音画同步、字幕及FFmpeg输出，尚未生成的素材不标为已验收。
