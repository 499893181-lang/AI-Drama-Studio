# 后续开发任务

本次交付范围是第一阶段“故事立项工作台”。后续阶段未接入，界面中的流程标识不代表已经具备生成能力。

1. **即梦创作剧本**：先确认本机即梦 CLI 是否存在独立文本剧本接口；帮助中的图片/视频提示词入口不能等同于剧本写作 API。若未暴露接口，需要确定受支持的替代衔接方式，保留用户确认与人工导入路径。
2. **Codex 审阅剧本**：建立人物、场景、关键道具的稳定 ID；区分用户锁定、AI 补充与待确认事实；输出独立审查报告和定向返工单，不能用自检替代独立审阅。
3. **即梦创作分镜 → Codex 检查**：先验证分镜接口，确定结构化分镜、起终态、动作与声音时间线的交接格式。上游改变后失效的审查结论必须重新验证。
4. **展示画风与预算**：接入真实价格或账户积分来源，定义货币/积分、预估与实际费用的关系；先展示可审阅方案，再执行用户授权范围内的任务。
5. **即梦生成画布及无配音视频**：验证画布创建/编辑和视频音轨控制接口，保存提交 ID、参数、版本与轮询状态，防止重复提交与重复扣费。
6. **后期配音、字幕和剪辑**：建立配音身份及授权记录，接入实测时长、字幕时间轴、剪辑工程与 FFmpeg 导出流程。
7. **导出完整视频**：检查画面、声音、字幕同步与完整性，提供独立媒体验收和导出记录；尚未生成的媒体不标记为已验收。

扩展方向：桌面打包、附件预览、项目导入导出、多版本创作说明对比、任务取消及恢复策略、跨平台运行验证。任何媒体生成或外部写入都应在接口能力和预算明确后单独实现。
