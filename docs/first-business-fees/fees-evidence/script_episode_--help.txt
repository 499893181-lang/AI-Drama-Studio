jimeng-novel script episode — AI 生成单集剧本（剧本工具）

用法: jimeng-novel script episode [选项]

参数:
  --project-id <string>
      画布 ID；不传时从当前目录向上找 .jimeng/config.json（jimeng-novel init 写入）
  --input <string>
      JSON 对象（高级入口，字段见 schema get）
  --input-file <string>
      从文件读取 --input 的 JSON
  --request-id <string>
      幂等键
  --wait <int>
      最多等待的秒数；不传只查一次；到期仍未完成返回 status=running（exit 0），再执行同一条命令即可，不要重新提交。建议值（2026-11-05 实测，提交到完成）：图片 120（n=59，p50 39s、p90 71s、max 136s）；视频 480（n=51，p50 221s、p90 319s、max 414s；seedance2.0_vision 最慢）。工具单次超时比这短时，按自己的超时给值，未完成就再跑 node result，或放进后台任务
  --out <string>
      成功后把剧本正文写进这个 md 文件；从不覆盖：已有文件内容不同（比如你改过）就先移到同目录 old/<名>.<序号>.md，输出里写明
  --characters <string>
      字段 characters（服务端必填）
  --characters-file <string>
      从文件读取 --characters
  --current-episode <int>
      字段 current_episode（服务端必填）
  --current-episode-summary <string>
      字段 current_episode_summary（服务端必填）
  --current-episode-summary-file <string>
      从文件读取 --current-episode-summary
  --future-summary <string>
      后续最多三集梗概，按「第N集 摘要」逐行
  --future-summary-file <string>
      从文件读取 --future-summary
  --history-summary <string>
      截止上一集的剧情回顾
  --history-summary-file <string>
      从文件读取 --history-summary
  --model-key <string>
      剧本模型 key；留空用 script_bird
  --plot-positioning <string>
      剧情定位：卖点、受众期待、情绪与调性
  --plot-positioning-file <string>
      从文件读取 --plot-positioning
  --previous-script <string>
      上一集剧本原文，第 1 集留空
  --previous-script-file <string>
      从文件读取 --previous-script
  --requirement <string>
      本集额外要求，如时长、字数、场数
  --requirement-file <string>
      从文件读取 --requirement
  --script-localization <cn|i18n>
      字段 script_localization
  --stage-content <string>
      字段 stage_content
  --stage-content-file <string>
      从文件读取 --stage-content
  --stage-episode-range <string>
      如 1-5
  --stage-sequence <int>
      字段 stage_sequence
  --story-engine <string>
      故事引擎：主线、目标、阻碍、代价（服务端必填）
  --story-engine-file <string>
      从文件读取 --story-engine
  --world-setting <string>
      字段 world_setting
  --world-setting-file <string>
      从文件读取 --world-setting
  --team-id <string>
      仅本次使用的空间；0 为个人。已有对象沿用原空间，新操作用账号默认；仅使用目录默认项目时校验目录绑定
  -j, --json
      输出 JSON 信封 {status,data,error,context}
  --jq <表达式>
      对 JSON 信封执行 jq（字符串结果原样输出），如 --jq '.data.items[].key'
  --full
      不截断长文本和长列表

示例:
  jimeng-novel script episode --current-episode 1 --story-engine-file <文件.md> --characters-file <文件.md> --current-episode-summary-file <文件.md> --wait 120 --out <文件.md>
